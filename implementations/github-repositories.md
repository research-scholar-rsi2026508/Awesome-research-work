# GitHub Implementations

## Self-RAG

**Repository:** https://github.com/AkariAsai/self-rag

Original implementation of Self-RAG: *Learning to Retrieve, Generate, and Critique through Self-Reflection*.

The repository includes:

- Installation instructions
- Quick start
- Retriever setup
- Training
- Inference
- Baselines
- Evaluation resources
- 7B and 13B models
- Training data

Self-RAG retrieves on demand, can skip unnecessary retrieval, and uses reflection tokens to critique evidence and generated content.

## TruthfulQA

**Repository:** https://github.com/sylinrl/TruthfulQA

Official implementation for the TruthfulQA benchmark.

Includes:

- Dataset
- Reference answers
- Evaluation code
- Demonstration notebook
- Multiple-choice evaluation resources

## RAG-Survey

**Repository:** https://github.com/Tongji-KGLLM/RAG-Survey

A repository accompanying the RAG survey. It organizes research papers, benchmarks, evaluation resources, datasets, and RAG toolkits.

## Reproducibility Note

The paper emphasizes that closed commercial RAG systems make independent verification difficult because researchers generally cannot inspect the retriever, index, prompting strategy, or other internal components.
